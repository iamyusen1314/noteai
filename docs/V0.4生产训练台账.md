## 已发现问题

- P0：旧标注链路所谓“AI 首审”实际是本地启发式规则，不是 Claude 主审；这会让 Kimi 复核和 V0.4 商业目标错位。
- P0：长批量标注遇到 Claude JSON 未转义引号时会中断整批，且中断前结果不落盘。
- P1：核心行业补充队列原先只覆盖美妆、家居、母婴，无法支撑第一批核心行业生产训练。
- P1：补充队列命中第一个行业即停止，容易把“健身餐/减脂餐”等跨词样本错分到美食。
- P1：只接受完全共识会浪费大量可用样本；但分歧样本不能直接进训练，需要保守裁决。
- P1：早期共识判断只读取归一化后的 `fact_status`，未同时检查 Claude/Kimi 原始事实风险字段，导致少量 `wrong_industry` 行可能被晋级。
- P1：V0.4 Preference ranker 曾按 `pair_id` 做验证切分，无法阻止同一内容出现在训练和验证两侧，导致 ranker 指标虚高。
