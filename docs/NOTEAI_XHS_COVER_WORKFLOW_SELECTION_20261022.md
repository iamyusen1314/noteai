## 1. 为什么选这个具体项目

[Editable-Design](https://github.com/yejy53/Editable-Design/tree/c87b16f6d7c198e2b6967f13f1b1baa939d6f31f/skills/editable-design)已包含营销图、封面、海报的完整流程与脚本：形成整体构图方向→准备/使用素材→真实HTML文字与图层→字体/DOM/遮挡检查→渲染PNG→实际看图修复→编辑与导出验证。不是只给一段美术prompt。原代码Apache2.0，字体采用带许可的版本化Fontsource包；只纳入本Skill，不搬论文/视频/演示文稿包。

[项目公开案例](https://github.com/yejy53/Editable-Design/tree/c87b16f6d7c198e2b6967f13f1b1baa939d6f31f/gallery)有完整中文营销brief、对应成图、编辑演示和执行回放。Root实际浏览了3:4茶饮成图：真实文字、明确主次、产品主视觉及信息模块可见。这只是作者演示，不能证明真实商家原照保真、市场点击率或NoteAI质量验收。

选择依据是可执行完整流程、原照可作为独立素材、中文真实文字、编辑验证和可审计来源。项目支持按每篇brief规划表达，不采用茶饮案例的颜色/字体作为统一风格，也不让用户替我们选择参考或担任设计师。公开案例不能充当市场成功数据；未经相应曝光/点击数据验证，不宣称“爆款”或提升CTR。

[OpenCode Skills](https://opencode.ai/v2/docs/skills/)能整包加载Skill和同目录脚本/参考；[SDK](https://opencode.ai/v2/docs/build/sdk/)可以在后台应用内运行，无须开启新的公网HTTP入口；[API](https://opencode.ai/v2/docs/api)有明确Skill激活、图片附件、持久session、等待/状态/事件。核到的源码是`anomalyco/opencode@7456ad872eecd5f7f857e2cbe9135c1407b12795`，根版本2.1.2、MIT。v2部分API表面标为experimental，必须固定版本并验证，不混用旧v1配置。

[自定义provider](https://opencode.ai/v2/docs/providers/)支持OpenAI-compatible端点和请求body；[图片](https://opencode.ai/v2/docs/attachments/)确实作为图像媒体传给模型；[请求/重试hooks](https://opencode.ai/v2/docs/build/plugins/)可接逐请求计量与否决自动重试。因此无需自己再写一套Agent宿主。实际Ark视觉/工具/思考协议、Puppeteer字体环境及成本闸仍未实测，这是接入验证内容。

## 4. 需要接入什么，哪些不重做

确认后需要4类工程接入，不称即插即用：

1. **运行环境与工具绑定**：固定完整Skill和OpenCode版本；准备Bun/OpenCode SDK、Skill所需Node≥22.12、Chromium/Puppeteer及字体。按job隔离文件与会话，关闭自动发现用户全局Skill/默认模型，只给封面需要的读写/渲染工具；把Skill的图像工具绑定现有Seedream适配器。实际依赖清单与许可证留档。
2. **统一物理调用闸**：所有主循环、审稿、自动标题/压缩等辅助请求及脚本图片请求都计入同一任务/原总预算；禁默认超时重试、付费fallback及UNKNOWN重发。OpenCode maxsteps、外层API次数或自报cost均不能代替物理调用/人民币账本。扩展现封面阶段内多请求的唯一身份/幂等记录，不再只用旧design/image/qc各一个物理ID；只走可观测HTTP模型通道，逐请求复用NoteAI共享模型并发租约，不让整任务长期占满原报告名额；验证请求钩子、失败与UNKNOWN恢复。
3. **成品与免费调整适配**：将项目HTML/文字层、原照hash/映射、最终PNG接入NoteAI白名单/权限/存储；后台使用固定字体/相同浏览器渲染修改。补运行门禁：强制初版原照＋实际成品共同送审并记录当前hash，无成功实际看图/审稿不得交付；这是NoteAI适配，原Skill的宿主自查和脚本不自动提供该强制保证。免费派生版按前述确定性验证及编辑差异记证据。不能直接把任意HTML或临时供应商URL当可交付资产。
4. **任务接线与受影响验证**：复用现有worker、幂等、断线重开、交付后唯一结算和PC/H5入口。渲染起始单并发、按新宿主资源核共享容量；不改支付/高德/报告正文，不搭新发布程序。若需要封面增量字段/迁移，届时仅列实际缺口，不夹带大版本。
