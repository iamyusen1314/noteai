## 验收标准

- 真实种草型餐饮：没有明确商家名时不调用高德，不出现“门店位于/套餐价格以/营业时间以/周末建议提前预订”等占位句。
- 到店决策型餐饮：有明确商家名和展示商家意图时才调用高德；真实查到的地址、人均、营业时间可以自然融入正文。
- 测评避坑型：缺少用户真实负面证据时不凭空编造缺点。
- 清单攻略型：多图/多菜品/多产品应覆盖多个视觉素材，不只围绕第一张图。
- 标题：不再把“这家真的稳/很稳/值得冲/闭眼冲”作为通用高分模板；三个标题结构必须有明显差异。
- 对话优化：继承原始创作方向，不在后续优化中擅自改成促成交或硬补事实。
